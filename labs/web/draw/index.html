How it draws. The room's light was baked once, light by light. Each frame the lights' brightnesses (their flicker, the dimmer) become four numbers, and every pixel reads its light from one texture: a few texture reads a pixel, no shadow maps, no compute shaders, which is why WebGL2 can draw it as well as WebGPU. Small things (the stools' legs, the candle) work out their four nearest lights per pixel.
