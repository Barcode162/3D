# The site: the front page

*Page and controls* · joshuavelasco.com · [all pages](README.md)

The front page: the headline (Dev → Publish → The site), the highlight, the news, what's inside the bar.

| Control | What it does |
|---|---|
| `ARCADE` | The arcade card. |
| `Come on in` | Into the bar (the closing call). |
| `Enter the bar` | Into the bar. |
| `Everything you can do in there` | What you can do inside (Bar3D's page). |
| `In progress` | A card's tag: in progress. |
| `LIVE CAPTURE` | The live picture card. |
| `Make an account` | A new account. |
| `MUSIC` | The music card. |
| `OPEN` | The bar is open (the card's tag). |
| `Planned` | A card's tag: planned. |
| `RACE` | The racing card. |
| `RHYTHM` | The 4K Mania card. |
| `See the bar` | Down to what the bar is. |

Card titles and tags read in capitals on screen.
