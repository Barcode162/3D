# The Studio

*Page and controls* · joshuavelasco.com/studio · [all pages](README.md)

The world editor ([the Studio](../systems/tools/studio.md)). Listed from its code (the Studio runs the game, too slow to open in a quick check): **change studio/ and this page together** (the piece tool refuses otherwise, unless `--docs-unchanged "<why>"`).

| Control | What it does |
|---|---|
| `+` | Bigger step. |
| `+ Lane` | Add a lane to the loop. |
| `+ State` | Add a state. |
| `A few words: what changed (optional)` | The publish note. |
| `A new box out of this face` | Building: pull a new box out of the face you picked. |
| `Add` | Opens the Library. |
| `Add something` | The same. |
| `Apply` | Put the proposal on your draft (one undo). |
| `Back to Dev` | Back to Dev. |
| `Back to my draft` | Stop previewing. |
| `Camera` | The camera's options. |
| `Copy` | Copy (a loop, a value). |
| `Copy loop` | Copy this loop to paste on another kind. |
| `Deselect` | Nothing selected. |
| `Discard` | Throw the proposal away. |
| `Drag to change; slide up for finer` | The fader: drag; slide your finger up for ten times finer. |
| `Drop` | Drop it on the surface below. |
| `Edit one of its parts` | The same. |
| `Every ` | Change every thing of this kind (not only this one). |
| `Fly` | Camera: fly freely. |
| `Local` | Move along the thing's own axes (else the world's). |
| `Lock the selection` | Taps don't change the selection. |
| `Log in` | Sign in (owner and admins). |
| `Make it` | Make the new box. |
| `Make the row` | Make a row of copies. |
| `Monitor` | The drawer: World, Inspect, Problems, Look, Life. |
| `New kind from this` | Make a new kind from this thing. |
| `New material` | Make a new material. |
| `Not yet` | Not now. |
| `Note for Claude` | Write a note about this thing; it goes to Dev's notes with a picture. |
| `Open the Monitor` | Opens it. |
| `Orbit` | Camera: turn around the selection. |
| `Part` | Edit one of its parts (solids, tap areas, seats). |
| `Password` | Your password. |
| `Paste` | Paste it. |
| `Place` | Put the new thing where you aim. |
| `Preview` | Show a proposal in the Studio (your draft is untouched). |
| `Proposals` | World changes Claude proposed. |
| `Publish` | Opens Publish: what changed, a note, then a new live version. |
| `Put it on another thing` | Moves it onto another thing (it follows that one). |
| `Redo` | Puts it back. |
| `Remove` | Remove it. |
| `Rename` | Rename it. |
| `Reset to kind` | Drop this thing's own change; use its kind's. |
| `Restore` | Bring an old version back (as a new version). |
| `Saved views` | Camera places you saved. |
| `Send to Claude` | Sends the note. |
| `Start over: back to the live bar` | Drop your draft; start from the live version. |
| `Test` | Sends an event to try a rule. |
| `The link to your draft` | The shared draft's address. |
| `This one` | Pick this one. |
| `Top` | Camera: look down from above. |
| `Try it with a friend first` | Share your draft: a code your friend opens in the bar. |
| `Undo` | Takes back the last change. |
| `Undo publish` | Takes the last publish back (a new version that restores the one before). |
| `Undo this publish` | The same, from History. |
| `Username` | Your username. |
| `Value` | The exact number. |
| `Walk` | Camera: walk like in the bar. |
| `What changed` | Your draft's changes in words. |
| `World` | Every thing, by what it sits on. |
| `±` | Plus or minus (the iPhone number pad has none). |
| `↔` | Swap the direction. |
| `−` | Smaller step. |
| `⋯` | More for the selection: Note for Claude, Part, Put on… |
| `▶ Hear it` | Plays its sound at the thing. |
| `✕` | Close. |
