# Dev → Overview → a Live tile

*Page and controls* · joshuavelasco.com/dev/#overview, tap a tile · [all pages](README.md)

A tile's sheet: what it says in full, a way to open it, and a reaction for Claude. A reaction is a note in Claude's notes (as from Plan → Tell Claude), naming the tile and what it said, with your words if you wrote some; Claude reads it at the start of the next session (Broke it first).

| Control | What it does |
|---|---|
| `A note about this (optional)` | Your words, sent with the reaction. |
| `Broke it` | Tells Claude this is broken. |
| `Close` | Closes the sheet (so does a tap outside it). |
| `Looks good` | Tells Claude this looks right. |
| `Note` | Sends your words about this tile (write them first). |
| `Open` | Opens what the tile is about (the bar, the deploy's run on GitHub, the job's page). Only on tiles that point somewhere. |
