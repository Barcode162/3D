# Dev → Projects

*Page and controls* · joshuavelasco.com/dev/#projects · [all pages](README.md)

Every project (from `toolbelt/tools.json`) as a card: its name (tap it, or the Open key under it, for the project's page), its state, what it is, and its tools as tiles to tap (a tool that's coming shows Soon). The tiles and the Open keys come from the data.

| Control | What it does |
|---|---|
| `Open` | Opens that phone report. |
| `Report code` | Type the 6-letter code a phone report gave you. |
