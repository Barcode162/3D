# The UI Editor

*Page and controls* · joshuavelasco.com/toolbelt/ui-editor/ · [all pages](README.md)

Edit the themes and screens every page wears ([the UI Editor](../systems/tools/ui-editor.md)). Tap a part in the preview or the list; its inspector shows below.

| Control | What it does |
|---|---|
| `Back to Dev` | Back to Dev → Projects. |
| `Computer` | The preview at computer width. |
| `Dark` | The theme's dark half. |
| `In game` | The preview as it shows over the game. |
| `Light` | The theme's light half. |
| `Phone` | The preview at phone width. |
| `Preview theme` | Which theme the preview wears. |
| `Publish` | Publishes your changes as a new version (asks for a login and a note). |
| `Redo` | Puts it back. |
| `Screen` | Edit a screen (its parts). |
| `Theme` | Edit a theme (its tokens). |
| `Undo` | Takes back the last change. |
| `Which screen` | The screen (or theme) being edited. |

The preview and the parts list show the screen being edited; their buttons are the screen's, not the editor's.
