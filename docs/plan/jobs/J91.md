# J91 · A real engine, step 4: ambient occlusion and volumetric light

**Chapter:** the engine
**Serves:** N3 N5
**From the user:** request `2026-10-25 #9` ("add MSAAx4 and ambient occlusion volumetric lighting and all")
**Verdict:** doable at a cost — phone speed: both are extra passes over the whole screen; the user asked for them, so they run at reduced size, each with an off switch and a quality setting, and the phone's report (J37) sets the default

## Goal
Corners, the gaps under the sofa and stools, and where a glass meets the
counter get a soft, real shade; the lamps, the neon and the fire throw
visible beams through a light haze. The bar looks deeper and warmer
without getting slower than the phone can hold.

## Where it stands
The renderer is forward (`looped/scene_renderer.cpp`, `looped/shaders/scene.wgsl`):
ambient occlusion only from a model's own baked texture (`occlusionMap`);
"haze" is a fog colour by distance, no beams. Shadows exist
(`looped/shadows.cpp`); MSAA arrives in J88.

## Design
- **Ambient occlusion (GTAO-style, screen space):** a depth-and-normals
  prepass at half size (it also lets the main pass skip hidden pixels),
  then occlusion from the depth around each pixel (a few directions, a
  short reach in metres, noise rotated per frame), a depth-aware blur, and
  the main pass multiplies only the ambient and bounced light by it (never
  direct lamp light: the light rule stays true). Works with J88's MSAA
  (the prepass is not multisampled).
- **Volumetric light (froxels):** the view cut into a coarse 3D grid
  (about 160×90×64 cells); a compute pass adds, per cell, the light each
  nearby lamp sends through the haze (its shadow map where it has one,
  J88's 3D lamp cells to find lamps fast), a second pass sums it front to
  back; the main pass and the transparent things read the grid (one
  lookup per pixel). Haze density per place and mood (`mood.h`), so the
  lounge can be clear and the stage smoky.
- **Switches:** Settings → Graphics: Soft shade (off / low / high), Light
  beams (off / low / high); `?ao=0`, `?fog=0`. Classic light and the tests'
  light leave both off.
- **Cost check:** `?perf=1` shows each pass's GPU time; target together
  under 2 ms on the phone (16.7 ms frame).

## Done when
The smoke test passes; pictures with each switch on and off differ only
where expected; the phone's report keeps the frame in budget.

## Risks
- Half-size AO can halo around thin things (stool legs): the blur follows
  depth; if it shows, low quality goes full size around edges.
- Beams can band in steps: noise per frame and a soft blend over frames.
- If together they cost too much on the phone, Low becomes the default.
