## Research (2026-10-26)
- The piano (`bar/piano.*`) played synth notes made in code (`looped/synth`), one every third key, pitched for the two keys around it, through one 3D emitter.
- "The Grandeur" (Native Instruments) is a paid library and can't be shipped. The closest free recording: Salamander Grand Piano V3 (Alexander Holm, a Yamaha C5, 16 loudness layers, CC BY 3.0: free with a credit). Its notes sit every third key from A0, the same grid the piano already uses.
- The engine could only make sounds from samples in memory; Web Audio decodes MP3 on every phone (decodeAudioData), so a sound from a file is a small addition (`Sound::load`, `audio.js` soundLoad).
- Size: 30 notes × 4 layers, 4–7 s each, stereo 96 kbps MP3 = 7.5 MB, fetched only when someone plays (the synth plays any note not yet arrived).
