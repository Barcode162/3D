## Goal
Looped is an engine you could build another game on: its own library, a
thin, named way to talk to the page it runs in, no bar names inside, and a
second small program (a place viewer) built from the engine alone, so the
boundary is proved by the build every time.

## Where it stands (Claude's review, 2026-10-25)
Engine and bar compile as one program; the engine names the bar's page
objects 68 times (`bar3dNet`, `bar3dAudio`, …); the renderer has bar limits
built in (7 other players, boxes sized for the Studio's X-ray).

## Scope
CMakeLists.txt (a `looped` library, the bar's `app` and a `viewer` linked
to it), looped/ (one host object instead of the bar's page names; limits
given at start instead of built in), bar/web (the page fills the host
object with its own parts), a check that keeps it so.
**Not in scope:** moving the bar's games out of bar/ (J40), a native
(desktop) build.

## Design
- `add_library(looped STATIC …)`; `app` (the bar) and `viewer` link it.
- The host: the engine talks to the page only through `window.loopedHost`
  (`net`, `audio`, `voice`, `log`, `perf`, `settings`, `account`,
  `bridge`); bar/web/index.html sets it from its own objects. A missing
  part is a no-op with one log line, so the viewer runs with almost none.
- `SceneRenderer::Limits` (other players, boxes) given at init.
- `tools/lint_engine.mjs` (in the quick check): looped/ never includes
  bar/, never names `bar3d…`.
- The viewer (`looped/apps/viewer/`): any place from the world files, its
  models, lights and loops (the engine's own place loader, moved from the
  bar's scene where it isn't bar-only), an orbit camera; served at
  `/looped/?place=showroom`.

## Pieces
- **J86.1** The library and the host: `looped` built on its own, every
  page call through `loopedHost`, the lint in the quick check. *Check:*

- **J86.2** Limits given at start, the place loader in the engine, and the

## Done when
The build makes both programs; the lint passes; the smoke test passes.

## Risks
A page call renamed wrongly breaks a feature quietly: the host logs every
missing part once, and the game's browser tests cover menus, voice and
multiplayer.
