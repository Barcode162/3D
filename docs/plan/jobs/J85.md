## Goal
Looped becomes a loop maker, the way a music app is: **patterns** (named
loops: sway, breathe, pulse, flicker…) live in a library, made once and
used by any thing; a place has a **timeline**, like a DAW's arrangement or a
video editor's tracks: tracks over things, **clips** of patterns placed at a
beat, for a length, faded in and out, layered on top of what each thing
already does. The whole place plays its timeline forever, on the shared
clock and on the music's beat, the same for everyone.

## Scope
The engine's world model (looped/world/) and its files: a loop library file
(`assets/world/loops.json`), `"@name"` to use a pattern wherever a loop goes,
and a place's `"timeline"`. The bar plays it (motion, glow and lamps follow
the clips); the room's copy of the world (cloud/sim) runs the same code. The
showroom gets a stage that plays a 16-beat show. The world store accepts the
new file.
**Not in scope:** the Studio's editor for it (J57, next), events placed on
the timeline (they wait for the script language, J79), sounds as clips.

## Design
Data (the schema and the Handbook's data pages gain both):
```json
// assets/world/loops.json
{"loops": {
  "breathe": {"period": 4, "pieces": [{"ch": "scale", "shape": "wave", "amp": 0.03}]},
  "pulse":   {"period": 1, "beat": true, "pieces": [{"ch": "glow", "shape": "beat", "amp": 1.5}]}}}
// a kind, a thing or a clip uses one by name
"states": {"idle": {"loop": "@breathe"}}
// a place's timeline
"timeline": {"length": 16, "beat": true, "tracks": [
  {"name": "Lamps", "on": ["#lamp-1", "#lamp-2"], "spread": 0.25,
   "clips": [{"loop": "@swell", "at": 0, "len": 8, "fade": 1, "mix": 1}]},
  {"name": "Stools", "on": "kind:bar_stool", "clips": [{"loop": "@spin", "at": 12, "len": 4}]}]}
```
- **Patterns:** `Library::addLoops(text)` reads a loops file; a loop field
  holding `"@name"` (a state's `loop`, a thing's or kind's `loops` entry)
  takes that pattern (resolved when the world is built; an unknown name is
  a problem `check()` names).
- **Timeline:** `length` in beats (`beat: true`, on the music's beat, 120 bpm
  when none plays) or seconds; time t = clock mod length. A clip is active
  for `at <= t < at + len` (it may wrap past the end); inside it the
  pattern runs from the clip's start (`speed` times as fast); its weight is
  `mix`, eased in over `fade` at both ends. `on` names things (`#id`),
  every thing of a kind (`kind:<id>`) or a list; `spread` puts each next
  thing that much of a cycle later (a wave along a row). Clip motion is
  **added** to each thing's own loop (layers, like automation on a track).
- `World::update` adds the timeline after the state loops; `setTimeline()`
  swaps it live (the Studio, J57); `check()` names unknown patterns and
  targets. Pure maths from the clock: the same on every phone and the room.
- The bar already maps channels to looks: `glow` → a model's glow, `light`
  → its lamp's brightness, `tint` → its colour, move/turn/scale → its place.
- The world store (studio/api.php) and the bundle accept `loops.json`.

## Risks
A heavy timeline over many things costs a little CPU each frame (measured in
the world test's 4000-thing bench). A pattern renamed in the library breaks
the clips using it: `check()` names them.
