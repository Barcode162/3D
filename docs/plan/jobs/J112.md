## Goal
Before any build, test or push, a quick checklist scans the project for the
obvious: a file changed without the file that must change with it, a model
without credits, two things with one id, a number kept in two files that no
longer matches. Each rule is one small file with one plain sentence of what
passing means; a broken rule names itself, the exact spot and the fix. New
rules are copy-paste from a template, one per file, sorted by area.
