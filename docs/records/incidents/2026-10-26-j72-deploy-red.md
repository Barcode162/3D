# Incident 2026-10-26: J72's deploy refused by the schema test

**Session:** [015cwLX4PmKxoTA3N6AscWbS](https://claude.ai/code/session_015cwLX4PmKxoTA3N6AscWbS)
**Errors counted:** 1
**Status:** closed

## What happened
J72 shipped `981a2a1`; GitHub's build stopped at its lint step
([run 242](https://github.com/Barcode162/3D/actions/runs/40305234132)):
`tools/schema_test.mjs` refused the place file: `things[...].turn: should be
a number`. The game deploy didn't go out; the live bar stayed on J100's build.

## Impact
Nothing broken live: J72 (the bottles and glasses as things) wasn't live
until the fix.

## Root cause
The wine rack's lying bottles and the champagne leaning in its bucket were
given a turn about three axes (`[90, yaw, 0]`). The engine reads that, but
the world's schema (and the Studio's Turn field) has a thing's turn as one
angle about the up axis. The world check run before saving (`bar_world_test`)
doesn't test the schema; GitHub does.

## Fix
J73.1: a tilted bottle gets a model of its own with the tilt built in
(`bottle_wine_1_tilt90_0.glb`...), its turn stays one angle; sizes are one
number.

## Proof
`tools/world_check.sh` (run by the piece tool whenever `assets/world/`
changes) now also runs the schema test and the materials test, the same
ones GitHub runs before a deploy.
