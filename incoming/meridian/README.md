# Meridian (the user's driving game, uploaded 2026-10-18)

An endless-drive game the user made (three.js 0.169 from jsDelivr, its own
Blender scripts in `blender/`, models and textures embedded as JS in
`assets.js`, `nature_glb.js`, `textures.js`). Kept here as uploaded; not built
into the site yet.

Plan (user, 2026-10-18): server work first, then add Meridian to the bar: it
opens full screen when you sit in a racing rig, you stay connected to the
room meanwhile. It uses three.js, an outside library: the first exception
to the from-scratch rule, which the user has to approve when it's added.
Check the licenses of any textures inside before publishing it.
